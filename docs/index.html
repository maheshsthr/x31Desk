05 / FAQ

Questions, answered carefully.

x31Desk is a Windows desktop workspace that brings notes, tasks and code snippets together in one focused app, with light and dark themes.

x31Desk is built for Windows. Other platforms have not been announced. See the release notes for the specific Windows versions covered.

x31Desk is designed as a local-first desktop app, so your workspace is stored on your own computer. Confirm exact storage details in the release notes for your version, and keep your own backups.
